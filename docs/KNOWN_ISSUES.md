# 已知问题与首次开源范围

整理日期：2026-11-12。应用版本标记为 1.2.0，首次公开从独立源码快照开始，不含原工作区历史。

## 登录保持

已修复自动续期请求遇到 HTTP 429（请求频率暂时受限）时误清除登录状态的分支。之后仍有微信隔一段时间要求重新登录的反馈，尚不能确定所有原因。

一次手机检查中本地存储可写、登录保存项存在、API 健康检查正常，只证明检查当时的状态，不代表几小时或隔天一定保持登录。源码不承诺永久免登录，也没有取消后端身份验证或保存明文密码。

## 导入与库存

微信收款助手导出的 Excel 不提供真实进货成本，需要自行填写核对。导入前预览，重复导入会检查已有记录。已盘点商品可能因库存不足阻止销售入库；补记历史小票可在选择文件前启用“仅补记销售，不改库存”，以页面实际预览为准。套餐不会自动分解扣减里面的单品。

小票导入组件采用已发布源文件快照，本地另一个默认只记销售的未发布补丁没有混入本仓库。

## 新环境与运维脚本

空白环境变量允许本地学习和构建，但不提供离线账本或演示登录。数据库、邮件、短信和托管由部署者独立配置。

API 代理、公开探针、TLS 证书工具与 public/login-check.html 保留原项目的固定域名、项目标识及诊断常量。它们不是可直接通用于所有项目的配置；必须理解并改成自己的参数后测试。证书工具主要面向 Windows，依赖单独准备的 acme-client，不是应用启动依赖，也不保证自动续期。不要直接执行真实签发或验收脚本。

docs 中有阶段验收与部署历史，记录的是当时证据，不表示所有未来环境都已测试。公开源码本身不包含线上账号、账本数据或供应商服务权益。
