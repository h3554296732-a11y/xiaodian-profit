## 排查与修复

1. 沙箱内依赖请求出现 ENOTFOUND；获准在本机环境联网安装后成功。因此没有把第一次下载失败归因于包不存在。
2. pnpm 默认的运行前自动安装，在受限环境中引发 store / symlink 权限问题。项目改为运行前警告、显式安装依赖；同步锁文件状态后 `pnpm typecheck`、构建和启动均正常。
3. 沙箱启动进程曾报告 Ready，但 HTTP 套接字受限、浏览器不可达；获准在本机权限下启动后，实际请求返回 HTTP 200。
4. 沙箱内生产构建在 Tailwind / PostCSS 子进程连接环节失败；本机权限下构建成功。没有通过删除样式或忽略错误绕过验证。
5. 开发浏览器日志发现 SVG title 的多个 JSX 子节点导致 React 渲染不一致；改成单个模板字符串，重新类型检查、生产构建及浏览器交互后未再捕获该错误。
6. 修复了利润说明锚点、各页面标题，统一了看板与商品页的示例商品，并提升辅助文字对比和手机说明字号。
